JC AV Timer Companion 0.8.2 - SOURCE / BUILD PACKAGE

This is NOT a ready-to-import Companion module archive.
Previous .tgz exports were manually assembled and were rejected by Companion.

To produce a package using Bitfocus official tooling on a Windows computer with internet access:
1. Install Node.js (compatible LTS release) if not installed.
2. Extract this ZIP completely.
3. Run BUILD-WINDOWS.bat and watch for errors.
4. If successful, use the generated .tgz with Companion > Manage Modules > Import module package (yellow button).
5. If it fails, send the command window error details and your Companion version.

NOTE: The existing module implements its own Companion IPC runtime. Bitfocus build tooling may require further adaptation, and these steps have NOT been successfully run/tested in this environment because registry dependencies were unavailable. Do not assume the built result works until validated in Companion.
