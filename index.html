    JC · AV TIMER

    Help & Setup

    Getting Started

    Enter a duration or choose a preset, then press Start. Start changes to Pause while running. Reset returns to the loaded duration. Stop sets the timer to zero.

    Live Timer

    Duration accepts colons or periods, so 8:00 and 8.00 both mean eight minutes. Countdown continues below zero in red until stopped, reset, or another cue is started.

    Timer Queue

    Add a duration and optional cue label. Use Play on any row to jump directly to it. Next Cue advances manually; there is no automatic follow.

    Presenter Messages

    Type any message and send it to the lower-third banner. Show/Hide keeps the message stored, Clear removes it, and Flash Message attracts attention without affecting the timer.

    Warnings

    Warnings automatically change the timer colour and use the same banner area. Manual presenter messages take priority. Every warning can have its own threshold, wording and colour.

    Appearance

    Dark/colour mode uses your selected colours. Light mode is a fixed light look; changing a colour automatically returns to colour mode. Chroma forces a flat key colour, disables gradients and shadow, and uses a hard outline.

    Output

    Display Timer Here takes over the current browser window. Open External Timer Window creates a separate clean output you can move to another display. Hover the bottom-right of the output for Fullscreen.

    Remote Viewer

    Start Remote Viewer hosting on this page with a username and password. Viewers open relay.justincreative.tech, enter the same details, and see the clean timer output over the internet.

    Bitfocus Companion

    Download the Companion module from the top bar. In Companion use Modules → Import custom module/package, then add JC - AV Timer. Keep the local API port at 3210 unless you deliberately change it.

    If you did not change the port in Companion, leave this at 3210.

    Offline App

    The offline package runs without internet. It can still use Companion locally and can work on a local Ethernet/Wi-Fi network. Internet Remote Viewer requires internet access.

    Keyboard Shortcuts

    Space Start/Pause · R Reset · Esc Stop · N Next Cue.

    Troubleshooting & Reset

    If the PiP looks stale, use Refresh PiP. If Companion is offline, check that the JC module is enabled and the port matches. Settings, queue, active timer and messages automatically recover after an accidental refresh.
