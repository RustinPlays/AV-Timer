    Help & Setup

    Connect Bitfocus Companion

    1. Download the module. Use Companion Module in the top bar below, or the button here: Download JC Companion Module.
    2. Import it. In Companion open Modules → Import custom module/package and choose JC-AV-Timer-Companion-0.7.0.tgz.
    3. Add the connection. Open Connections → Add connection, search JC, then choose JC - AV Timer.
    4. Keep the Local browser API port at 3210 unless something else is already using it. Save/enable the connection.
    5. Keep Companion and this operator timer open on the same laptop. The webpage can still come directly from GitHub.
    6. Test it below. The top status should settle on Companion connected.
    7. Add Stream Deck buttons. In Companion Presets search JC. You will find live TIMER / HH / MM / SS displays, transport, quick Add / Remove / Start / Set presets, Queue controls, and single-toggle display features with live ON/OFF feedback.
    If you did not change the port in Companion, leave this at 3210.

    Offline App

    The GitHub page is the normal online version. Use Download App if you need the timer with no internet connection.

    The offline ZIP contains only normal HTML/CSS/JavaScript files plus the Companion module. There is no EXE, MSI, CMD, BAT or PowerShell launcher, so there is no Windows executable to unblock. Extract it and double-click JC AV Timer.html.

    External Display

    Use Open Output, move the output window to the second display, then move your mouse into the bottom-right corner of the output. The Fullscreen / Exit Fullscreen button appears only while you hover there.

    If Companion will not connect

    Make sure Companion is running, the JC - AV Timer connection is enabled, the ports match, and Edge/Chrome is allowed to access localhost/local-network services if it asks. Only one JC module connection can listen on the same port at a time.
