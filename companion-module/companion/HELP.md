# JC AV Timer v0.9.3

Controls the JC AV Timer operator site through the local API bridge on the same computer.

## Setup
1. Open timer.justincreative.tech in your browser.
2. Import the packaged `.tgz` from Companion's **Modules** page.
3. Add the **JC AV Timer** connection.
4. Keep the Local API Port at 3210 on both the module and the website.

## Clock
The Clock / Timer preset toggles the output between the timer and the live clock.
Use the Show Clock, Show Timer, and 12/24-hour format actions to choose the mode.
Live clock variables include seconds. This is a local browser-controlled timer;
the computer running the website controls the local time zone.
