# JC AV Timer for Companion

Control the JC AV Timer from Bitfocus Companion 5.1 or later.

1. Open the timer at https://timer.justincreative.tech on the **same computer** as Companion.
2. Add a **JC AV Timer** connection in Companion.
3. Leave the local API port at **3210**, unless you changed it on the timer.
4. Use the provided presets for Start/Pause, Reset, Stop, Next Cue, Timer/Clock toggle, 12-hour clock, 24-hour clock, time adjustment and live timer variables.
5. With Clock Mode enabled, output shows the current system clock with seconds.

This module uses a local HTTP bridge at 127.0.0.1. If disconnected, verify that the browser timer is open and the ports match.
