# Connect Bitfocus Companion

1. Download `downloads/JC-AV-Timer-Companion-0.6.0.tgz`.
2. In Companion open **Modules → Import custom module/package** and choose `JC-AV-Timer-Companion-0.6.0.tgz`.
3. Open **Connections → Add connection**.
4. Search **JC** and add **JC - AV Timer**.
5. Leave the local timer API port at **3210** and enable/save the connection.
6. Open JC AV Timer on the same laptop from GitHub Pages or the offline files.
7. Wait for the timer top bar to show **Companion connected**.
8. In Companion Presets search **JC**.

Preset groups:

- `JC · Control`
- `JC · Add`
- `JC · Remove`
- `JC · Start`
- `JC · Set`
- `JC · Queue`
- `JC · Queue Add`

Quick time presets use 1, 2, 5, 10, 15, 20, 30, 45 and 60 minutes.

Live TIMER / HH / MM / SS, Pause / Resume, status, warning and toggle feedback are calculated and refreshed inside the Companion module once it has the timer's wall-clock state.
